# Changelog

All notable changes to GeoPlot are documented in this file.

## 0.1.0 - 2026-09-13

- Created GeoPlot as a standalone repository and Windows desktop product.
- Applied the selected top-left icon across the app window and installer.
- Preserved local-only processing and explicit human recipe confirmation.
- Preserved separate wt% and ppm analyte/unit contracts.
- Added project rename, reversible removal, and restoration.
- Added responsive single-page behavior at supported window sizes.
- Bundled and parity-tested the GeoSkills scientific engine.
