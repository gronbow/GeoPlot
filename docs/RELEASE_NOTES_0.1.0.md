# GeoPlot 0.1.0

GeoPlot 0.1.0 is the first standalone Windows desktop package for the GeoPlot
application.

## Highlights

- Local-first import and review of XLSX, CSV, and TXT geochemistry tables.
- Fixed 47-analyte contract with distinct wt% and ppm review options.
- Explicit human confirmation before plan creation and execution.
- Project rename, reversible removal, and restoration.
- Responsive single-page desktop interface.
- New GeoPlot product name and the selected G-and-strata icon.
